# Employee Management System

A web-based Employee Management System built with ASP.NET Web Forms, Dapper, MySQL, and Bootstrap. The application enables administrators to manage employee records efficiently with secure authentication, role-based access control, bulk employee onboarding, reporting, and audit tracking.

## Features

### Employee Management

## Features

- Admin-only access to Create, Read, Update, and Delete (CRUD) operations
- Employee-specific Notes and Activity Tracking
- Bulk Document Upload with Rollback Support
- Email Service Integration
- Custom Fields Management
- Automatic Session Logout Based on Timeout
- Unauthorized Page Access Restrictions
- Advanced Filtering and Search Functionality
- Employee Reminder and Follow-up Management


### Security
- Login-based authentication
- Role-based authorization (Admin/User)
- Secure session management

### Bulk Employee Upload
- Upload employee data through CSV files
- Background job processing
- Rollback support for failed uploads
- Upload job history tracking

### Reporting
- Employee report generation
- Export reports to CSV
- Export reports to PDF

### Audit & Activity Tracking
- Employee creation tracking
- Employee deletion tracking
- Bulk upload activity logs
- Email delivery logs

### Email Integration
- Automatic welcome emails for newly created employees
- Email status tracking and error logging

## Technology Stack

- ASP.NET Web Forms
- C#
- Dapper ORM
- MySQL
- Bootstrap

---

## Employee Directory

The Employee Directory screen provides a centralized view of all employee records with powerful search and filtering capabilities.

### Capabilities
- Search employees by code or name
- Filter employees by department
- Pagination support for large datasets
- Quick employee management actions
- Responsive Bootstrap-based UI
